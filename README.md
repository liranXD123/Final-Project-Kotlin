# ⛅ Weather Forecast App

אפליקציית מזג אוויר מתקדמת לאנדרואיד (Native) שפותחה כפרויקט גמר. האפליקציה מציגה נתוני מזג אוויר בזמן אמת, תחזית שבועית ומדדי זיהום אוויר, תוך שימוש בארכיטקטורת MVVM מודרנית ותמיכה מלאה במצב לא מקוון (Offline Cache).

---

## ✨ תכונות מרכזיות (Features)

* **מזג אוויר מבוסס מיקום:** זיהוי אוטומטי של מיקום המשתמש (GPS) והצגת נתונים עדכניים.
* **איכות אוויר (Pollution):** קריאת רשת ייעודית המציגה את מדד ה-AQI ורמות המזהמים.
* **תחזית שבועית (Offline-First):** תצוגת תחזית ל-5 ימים השומרת את הנתונים במטמון מקומי (Room). מאפשרת חוויית שימוש רציפה גם ללא חיבור לאינטרנט.
* **עדכונים חיים ברקע:** רשימת ערים נבחרות המתעדכנת אוטומטית ברקע באמצעות WorkManager, גם כשהאפליקציה סגורה.
* **ניהול מועדפים:** רשימה דינמית המאפשרת הוספה, חיפוש ומחיקה (Swipe to Delete) של ערים מועדפות באמצעות מסד הנתונים המקומי.
* **התאמה אישית (Settings):** תמיכה מלאה במצב כהה (Dark Mode) ומעבר קל בין יחידות מידה (צלזיוס ופרנהייט).
* **לוקליזציה מלאה:** תמיכה אינטגרלית בשפות עברית ואנגלית בהתאם להגדרות שפת המערכת של המכשיר.

---

## 🛠️ טכנולוגיות וספריות (Tech Stack)

* **שפת פיתוח:** Kotlin
* **ארכיטקטורה:** MVVM (Model-View-ViewModel) בשילוב Repository Pattern
* **רשת (Networking):** Retrofit2 לניהול קריאות ל-OpenWeather API
* **מסד נתונים מקומי:** Room Database (שמירת מועדפים ומטמון תחזית)
* **הזרקת תלויות (DI):** Dagger-Hilt לניהול רכיבי המערכת
* **אסינכרוניות:** Kotlin Coroutines ו-Flow להזרמת נתונים חיה ורציפה
* **עבודות רקע:** WorkManager
* **ניווט:** Jetpack Navigation Component למעבר יעיל בין מסכים
* **עיבוד ותצוגת תמונות:** Glide (לטעינת אייקוני מזג אוויר באופן דינמי)

---

## 🏗️ ארכיטקטורה וזרימת נתונים (Data Flow)

האפליקציה נבנתה לפי העיקרון של **מקור אמת יחיד (Single Source of Truth)** בשכבת התצוגה:
1.  **Remote API:** ה-Retrofit מושך את הנתונים החדשים מהשרת.
2.  **Repository:** מנהל את הלוגיקה העסקית, מתרגם את נתוני ה-JSON ושומר אותם במסד הנתונים המקומי.
3.  **Room DB:** מתעדכן ושומר את המידע העדכני ביותר על המכשיר.
4.  **Flow:** פותח "צינור" מידע חי ממסד הנתונים ודוחף אוטומטית שינויים ל-ViewModel.
5.  **UI:** מסכי ה-Fragment מתעדכנים דרך LiveData מתוך ה-ViewModel, ללא גישה ישירה ויקרה לאינטרנט.
